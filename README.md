## 🎮 About The Game

This is a classic **Pong arcade game** - one of the first video games ever made! Two players control paddles on opposite sides of the screen, trying to hit a ball past their opponent. 

This version was built during a 90-minute Git & Python workshop. The code includes `# TODO` comments marking where I made customizations to make the game uniquely mine.

## 🎯 Game Controls

| Player | Move Up | Move Down |
|--------|---------|-----------|
| **Left Player** | `W` key | `S` key |
| **Right Player** | `↑` (Up Arrow) | `↓` (Down Arrow) |

**First to 5 points wins!** (Or whatever score I changed it to 😄)

## 🚀 How to Run This Game

### Prerequisites
- Python installed on your computer
- Git (optional, for cloning)

### Steps

1. **Clone this repository:**
```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
```

2. **Navigate to the project folder:**
```bash
cd YOUR_REPO_NAME
```

3. **Install Pygame:**
```bash
pip install pygame
```

If you get a permission error, try:
```bash
pip install --user pygame
```

4. **Run the game!**
```bash
python main.py
```

If that doesn't work, try:
```bash
python3 main.py
```

## 🎨 Want to Customize It More?

Open `main.py` and look for `# TODO` comments - they mark spots where you can easily change:

Each `# TODO` includes hints to help you get started!
